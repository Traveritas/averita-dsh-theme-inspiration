昼雾与靛夜

四套主题：昼雾 · 靛夜 / 冷晨 / 暮玫瑰 / 暮紫。浅色与深色各一套令牌，背景二选一：点阵或流光。所有颜色都落到 --dsw-alias-* 上。

  • 点阵：10px 网格、1.5px 点；漂移 60s 一程、呼吸 30s 一程，可关；
  • 流光：1/5 分辨率噪声场，5px 一格、30fps，默认跟随主题，另有四套固定色板；
  • 两者共用缩放 / 浓淡两条滑杆；流光另有速率，减少动效时全停。
theme.cssbody::before {
  animation:
    avDotDrift 60s linear infinite alternate,
    avDotBreathe 30s ease-in-out infinite alternate;
  will-change: transform, opacity;
}

先在预览里看比例和材质，再决定要不要装进 DSH。
